# Markdown Renderer

A modern, responsive Markdown Renderer built with React. Upload `.md` files, preview them instantly, and copy the rendered content with syntax highlighting and dark mode support.

## ✨ Features

- 📄 Upload Markdown (.md/.markdown) files
- ⚡ Instant live preview
- 🌙 Dark & Light mode
- 🎨 GitHub-style Markdown rendering
- 🖍️ Syntax highlighting for code blocks
- 📋 Copy Markdown content
- 📱 Fully responsive design
- 📂 Drag & Drop file upload
- ⚠️ Error handling for invalid files

## 🛠️ Tech Stack

- React
- Vite
- Tailwind CSS
- React Markdown
- Remark GFM
- Rehype Highlight
- Lucide React
